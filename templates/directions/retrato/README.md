# Retrato em Contraponto

Direção visual reutilizável montada por `gerar_retrato.py`. O layout mantém a
paleta verde/oliva como padrão configurável, componentes acessíveis e fallbacks
para as fotografias principal e de abordagem. Esta direção é usada pelo fluxo oficial `gerar.py` para `public/`, além da
prévia isolada de `gerar_retrato.py`. Caderno Contemporâneo não integra o build.
