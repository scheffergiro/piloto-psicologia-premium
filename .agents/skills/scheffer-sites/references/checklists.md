# Checklists

## Pré-merge

- escopo respeitado
- visual preservado quando exigido
- copy preservada quando exigido
- CTA e links validados
- assets presentes
- headings e semântica revisados
- acessibilidade afetada revisada
- SEO afetado revisado
- testes executados
- diff sem artefatos inesperados

## Pré-publicação

- dados confirmados
- domínio definitivo
- canonical
- robots
- sitemap
- headers
- Open Graph
- JSON-LD quando pertinente
- contatos
- WhatsApp/formulários
- desktop
- mobile
- teclado
- imagens
- performance básica
- requisitos do nicho verificados em fonte atual

## Migração de domínio

- domínio antigo e novo confirmados
- acesso ao domínio, DNS, hospedagem e Search Console mapeado
- URLs antigas importantes mapeadas para destinos equivalentes
- protocolo HTTP/HTTPS e variantes www/sem www testados
- homepage e caminhos antigos representativos testados
- status HTTP, Location, destino final e saltos verificados
- propriedades/variantes relevantes do Search Console verificadas
- Alteração de endereço enviada quando aplicável
- sitemap novo enviado e monitoramento definido
- prazo de domínio, DNS, hospedagem e redirecionamento documentados
- cliente informado sobre o impacto do vencimento ou cancelamento

## Retrospectiva

- qual erro gerou retrabalho?
- qual decisão merece teste?
- qual aprendizado é universal?
- qual é específico do nicho?
- qual deve permanecer específico do cliente?
- qual regra existente precisa ser removida?
