# Core Reference

## Princípios operacionais

1. Contexto antes de padrão.
2. Jornada antes de CTA.
3. Clareza antes de volume.
4. Identidade confirmada antes de metadata.
5. Preview separado de produção.
6. Fonte separada de artefato gerado.
7. HTML semântico antes de ARIA adicional.
8. Teste decisões que não podem regredir silenciosamente.
9. Não invente evidência para aumentar conversão.
10. Conformidade regulatória deve ser verificada em fonte atual.

## Perguntas de revisão

- O visitante entende quem, o quê, para quem e como?
- Cada seção possui função própria?
- O CTA está adequado ao ponto da jornada?
- A página funciona em mobile?
- A hierarquia é semântica?
- O preview está protegido?
- A produção possui um único domínio de referência?
- Existe algum dado inventado ou não confirmado?
- A mudança atual resolve um problema real?
